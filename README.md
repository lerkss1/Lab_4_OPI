
Лабораторная работа №4. Циклические алгоритмы
Цель работы
Изучение циклических конструкций языка Python (for, while), вложенных циклов, а также отработка навыков работы с условными операторами, модулями (random, time), обработкой исключений (try-except) и строками.
Выполненные задания (Базовый уровень А)
A1. Тренажер таблицы умножения
Описание: Программа генерирует N случайных примеров на умножение (числа от 2 до 9). Пользователь вводит ответы. Программа проверяет их и замеряет время, затраченное на каждый пример.
Особенности реализации:
· Использован модуль random для генерации чисел.
· Использован модуль time для замера времени (time.time()).
· Реализована защита от некорректного ввода (если введено не число, программа просит повторить ввод, не прерывая тест) с помощью конструкции try-except внутри цикла while True.
· В конце выводится подробная статистика: общее время, среднее время, количество и процент правильных ответов.
A2. Вложенные циклы (Графические фигуры)
Описание: С использованием вложенных циклов for программа отрисовывает из символов # три фигуры: прямоугольник (nxm), правый треугольник и рамку (nxm). Размеры вводятся с клавиатуры.
Особенности реализации: Для перехода на новую строку после отрисовки ряда используется print() без аргументов, а для печати символов в одну строку — print("#", end="").
A3. Анализ сетевых пакетов
Описание: Программа анализирует строку, состоящую из 0 (потерянные пакеты) и 1 (успешно доставленные).
Особенности реализации:
· Валидация ввода: строка должна состоять только из 0 и 1 и иметь длину не менее 5 символов.
· Поиск самой длинной последовательности нулей реализован через цикл for с использованием счетчиков current_streak и max_streak.
· Вычисляется процент потерь и на его основе выводится вердикт о качестве связи (от «Отличного» до «Критического»).
A4. Валидатор номеров кредитных карт
Описание: Программа проверяет валидность номера банковской карты.
Особенности реализации: Реализован алгоритм Луна (Luhn algorithm). Цифры номера перебираются с конца, каждая вторая умножается на 2 (с вычитанием 9, если результат больше 9). Если итоговая сумма делится на 10 без остатка — номер считается корректным.
